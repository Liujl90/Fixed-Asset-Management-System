# 企业固定资产全生命周期管理系统 Demo

这是一个基于 Vue 3、Element Plus 和 ECharts 的交互式前端 Demo，用于验证 MVP 产品设计中的页面结构、角色权限和资产业务闭环。

## 体验内容

- 管理员与普通员工两种体验身份。
- 部门、员工和资产分类管理。
- 固定资产登记、编辑、删除、详情和条件查询。
- 员工提交领用申请，管理员确认领用。
- 员工提交归还申请，管理员确认归还。
- 在用资产跨部门、跨负责人调拨。
- Dashboard 资产状态、部门分布和最近变动统计。
- 用户、角色和基础菜单权限配置。

Demo 暂不连接后端，数据保存在浏览器本地，可通过页面顶部的“重置数据”恢复初始状态。

